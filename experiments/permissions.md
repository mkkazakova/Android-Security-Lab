# Runtime Permissions: P1-P3

Исследуется механизм управления разрешением
`android.permission.CAMERA` на Android 13 и Android 16.

Проверяется состояние разрешения внутри приложения
SecurityClient через Android API `checkSelfPermission`.

## Эксперименты

| ID | Подготовка | Ожидаемый результат |
|---|---|---|
| P1 | Отзыв разрешения CAMERA | DENY |
| P2 | Выдача разрешения CAMERA | ALLOW |
| P3 | Повторный отзыв CAMERA | DENY |

## Методика

1. Установить тестовые приложения.
2. Подготовить необходимое состояние разрешения через ADB.
3. Запустить PermissionProbeActivity.
4. Проверить состояние разрешения внутри приложения.
5. Сохранить результат и журналы.
6. Повторить на другой версии Android.

## Ограничения

Испытание проверяет механизм контроля разрешений
приложения, но не работу физической камеры.

Выдача и отзыв разрешений автоматизированы через ADB.
Пользовательские диалоги предоставления разрешений
в этих сценариях не исследуются.

Отзыв разрешения может завершить процесс приложения.
Поэтому перед проверкой запускается новая Activity.

Результаты сохраняются в report.json.
